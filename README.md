## This repository

Source for emilfreijd.se, a bilingual portfolio built with Astro and deployed to GitHub Pages.

For local development, use Node.js 22 and run `npm ci` followed by `npm run dev`. Run `scripts/verify.sh` to test, check, and build the site.

See the [security policy](SECURITY.md) to report a vulnerability privately.
