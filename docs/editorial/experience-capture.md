# Fånga en erfarenhet

Använd när du ännu inte vet vilket format materialet passar för. Börja med [den gemensamma instruktionen](README.md#gemensam-instruktion-för-alla-intervjuer) och fortsätt med följande prompt.

```text
Intervjua mig om en erfarenhet som kan vara värd att dela.

1. Vad hände, när och i vilket sammanhang? Varför spelade det roll?
2. Vilket problem eller mönster lade jag märke till? Vad kan jag belägga?
3. Vad gjorde jag själv, vad gjorde andra och varför valde vi det sättet?
4. Vilka alternativ fanns? Vad fungerade sämre eller överraskade mig?
5. Vad blev utfallet? Vilken del är fortfarande okänd?
6. Vad lärde jag mig och vad skulle jag göra annorlunda?
7. Vem skulle ha nytta av detta och vad ska den personen få med sig?
8. Vilka detaljer, bilder och exempel får visas offentligt?

Sammanfatta kärnidén i två meningar och föreslå ett format:
project/case för ett konkret angreppssätt, essay för ett resonemang,
update för en kort lärdom. Föreslå att behålla materialet privat om det
ännu saknar läsarvärde. Lista vad som saknas för nästa steg.
```

Gå vidare till [projekt](project-intake.md), [essä](essay-intake.md) eller [uppdatering](update-intake.md). Spara den privata intervjun separat från den text som får publiceras.
