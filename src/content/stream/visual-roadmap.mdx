## One timeline, two kinds of decision

At the Swedish National Courts Administration, I used roadmaps to set a longer-term direction. Putting activities on the same timeline makes it easier to see how they fit together and which decisions have to come first.

In my current role, I have started using them for a more practical question. What needs to be underway now so the right conditions and skills are in place a few months from now? In the fictional example, the test environment takes twelve weeks to prepare. If that work is scheduled too late, the roadmap flags the latest date it can start.

## How I use the views

- **Three months.** Read the plan week by week. Check upcoming handovers, who owns them and which preparations need to start.
- **One year.** See where major activities and milestones overlap. Check whether the same team has capacity for several pieces of work at once.
- **Three years.** Add the major stages that show the direction of travel. Break down the next stage once you have enough information to make concrete commitments.

Add a dependency when one activity actually has to finish before another can start. If a milestone moves, use the suggested latest start to decide whether to change the timing, scope or staffing.
